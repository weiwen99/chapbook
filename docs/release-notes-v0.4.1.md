# chapbook v0.4.1 — 独立阅读导航

Markdown、Org、代码、Office／CSV 的独立阅读页现在使用自己的吸顶导航，不再复用文件浏览工具区。
顶部显示文件位置与实际文件名，返回目录、进入文件树和文件操作各有明确入口；目录、搜索结果和
树视图内部的浏览工具区保持原有布局。相对 v0.4.0，CLI、渲染依赖与单文件分发方式不变。

## 阅读导航

- **文件位置** — 可点击的路径面包屑从服务根目录开始，顶栏显示实际文件名，正文标题留在正文。
  路径沿用当前访问的符号链接别名；特殊字符继续安全转义显示，不用显示文本重建文件地址。
- **所在目录** — 固定进入当前文件的父目录，沿用保存的浏览视图（无偏好时为列表）与当前排序／
  隐藏规则。只选中并滚动到可见文件，不自动打开预览、不改变偏好，也不为定位强行显示隐藏项。
- **在文件树中浏览** — 在树中继续阅读当前文件，新增一个历史项；后退恢复独立阅读页及原滚动位置，
  前进恢复文件树。同一浏览位置内的列表／网格／树切换仍沿用原有历史语义。
- **按需搜索** — 文件搜索不再常驻大输入框。点击搜索或按 `/` 展开并聚焦，Escape 收起并返回入口；
  提交进入既有文件名搜索结果页，保留当前显示规则，不实时替换正文。本文查找仍使用浏览器的
  `⌘F / Ctrl+F`。
- **原文件与链接** — 下载返回原始文件，而非渲染 HTML；复制当前页面 URL，保留已有章节锚点。
  剪贴板不可用或拒绝写入时，提供已选中的完整链接供手动复制，不显示虚假的成功反馈。
- **宽窄屏与滚动** — 宽屏为单行导航，长路径可展开查看；窄屏保留“所在目录＋文件名＋更多”，
  完整路径与次级操作均可在“更多”中访问，不依赖悬停。顶栏滚动时保持可见，章节跳转为其留出空间。
- **无 JavaScript** — 所在目录、面包屑、原生搜索表单和下载链接仍可用；依赖 JavaScript 的文件树与
  复制按钮不显示。亮暗主题继续沿用现有配色，不引入外部资源。

## 兼容与升级

- **保持原有行为** — 目录、搜索结果和树内浏览控件不重设计；PDF 仍交给浏览器原生查看器。
  CLI、Range、响应模式优先级、路径编码、可信页面安全响应头与 native-open 能力边界不变，未新增依赖。
- **升级提醒** — 前端资源内嵌在二进制中，需要替换为新二进制并重启原有 chapbook 进程；无需数据迁移。
- **发布平台** — Linux x86_64（`x86_64-unknown-linux-musl`，musl 静态链接）与 macOS Apple Silicon
  （`aarch64-apple-darwin`）。其他平台可从源码构建。
- **使用说明** — 见 [README：Reading](https://github.com/weiwen99/chapbook/blob/v0.4.1/README.md#reading)；
  实施与验收记录见[阅读导航规格](https://github.com/weiwen99/chapbook/blob/v0.4.1/.scratch/reading-navigation/spec.md)。
