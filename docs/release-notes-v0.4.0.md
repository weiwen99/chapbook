# chapbook v0.4.0 — 统一的浏览控件与显示规则

树、列表、网格三个浏览视图现在共用同一个顶部工具区：统一的图标入口、共享的隐藏项开关与
六键双向排序；显示规则可以随 URL 分享，也能在本机偏好与浏览器历史中恢复。本次同时修复了
树目录手动折叠后刷新被重新展开的回归。相对上一版 v0.3.1，CLI、Range 请求与渲染依赖不变，
仍是单文件可执行、零运行时外部依赖。

## 新功能

- **统一的三视图工具区** — 树、列表、网格改为工具区中同一组自包含 SVG 图标，带 hover 与
  键盘焦点提示、可访问名称和互斥选中态；窄屏时整组换行，不拆散视图图标。左侧搜索，右侧
  集中放置视图图标、隐藏项开关和排序入口；默认列表视图、名称升序、不显示隐藏项。
- **共享的隐藏项开关** — 三个视图与搜索、目录预览共用同一个开关。按条目自身 basename 是否
  以 `.` 开头判断（符号链接按链接名），只影响浏览与搜索显示，不限制直链、原文与下载；
  根目录树遍历与全局搜索会跳过隐藏目录分支。隐藏当前选中项时，选择回退到最近的可见祖先
  或最近的可见条目（为空时不选中条目），不打开回退项，也不改变当前路径、查询或文档锚点；
  重新显示会恢复此前展开的分支，但不抢回焦点。
- **六键双向排序** — 名称、末尾扩展名类型、大小、修改时间、访问时间、创建时间六项，每项可
  升序或降序；作用于目录、树同级节点、搜索结果与目录预览。目录始终排在文件前，升降序只
  影响组内；同值固定按名称、完整相对路径升序。名称按原始字节、区分大小写、不做自然排序
  （`file10` 在 `file2` 前）；类型取末尾扩展名并忽略 ASCII 大小写（`a.tar.gz` 是 `gz`，
  `.env` 无扩展名）；目录大小是自身元信息长度，不递归统计；创建时间不可用时依次回退修改
  时间、epoch。
- **搜索：先过滤，再取 500 个候选，最后排序** — 服务端递归文件名搜索仍然不建索引：先按当前
  隐藏规则过滤，再以确定性 BFS 收集最多 500 个合格候选，最后按当前显示规则排序展示。被过滤
  的条目在登记遍历 identity 与占用候选名额之前就被跳过，因此不提供「全根目录最新/最大 500
  条」式的全局 Top-N。扫描进行中的并发请求仍返回 429 + `Retry-After: 1`。
- **显示规则可分享** — `?sort=Column:Order&hidden=0|1`（如 `?sort=Size:Desc&hidden=1`）在后续
  目录与搜索导航中延续，重新搜索保留规则，离开搜索才移除 `q`；非法排序或隐藏值返回 404。
  URL 只携带路径、查询与显示规则，不携带浏览布局；`view=1` 仍表示文件强制渲染。
- **偏好、历史与恢复** — 三个视图共享同源的界面偏好。冷访问按「显式 URL > 保存的偏好 >
  默认」取规则；历史项、reload 与 BFCache 优先恢复自己的快照，不被其他标签页改动的偏好
  覆盖。控件只保存用户实际改变的字段（冷启动不写入默认值）；同一浏览位置上的视图/隐藏/
  排序变化不新增历史，只有实际的目录、文件或搜索导航才新增一个历史项。从旧版本升级时，
  浏览器中已有的视图偏好会一次性迁移：保存过树视图的继续使用树视图，否则保留原有的
  列表/网格选择，旧键随后删除。
- **保持打开文档的 live 状态** — 切换排序或隐藏只更新受影响的条目区域，不重新转换已经打开
  的文档正文，不收起树、不回根目录；树的分支加载按规则版本提交，过期的成功与错误结果都
  不会覆盖新状态。
- **键盘与窄屏** — `v` 在浏览视图内按列表→网格→树→列表循环，输入框、可编辑区域与修饰键
  组合不触发；`j/k/↑/↓`、`Enter`/`o`、`p`、`/`、`Backspace` 与树内方向键行为不变。排序
  入口可用 Tab/Enter 打开并选择方向，摘要显示当前生效的规则；窄屏下抽屉与预览面板位于
  工具区下方，排序菜单与提示不会被遮挡或裁出。
- **无 JS 渐进增强** — 禁用 JavaScript 时，列表的隐藏、排序、搜索与导航使用真实的服务端
  链接与 GET 表单，沿用 URL 参数与默认值，不读浏览器偏好、不使用 cookie；树与网格仍需要
  JavaScript（无 JS 时入口标注为不可用）。
- **独立阅读页** — 文档直链保持完整阅读布局，不注册为第四种浏览视图：三个图标都不标为
  已选，隐藏/排序入口禁用并提示「阅读模式不适用：请先在目录或搜索中使用」。点列表/网格
  图标回到父目录并定位该文档，点树图标在树中打开该文档；文档进入树后的亮/暗背景与正文
  配色一致。

## 修复

- **树目录折叠后刷新又被展开** — 手动折叠的目录现在会在刷新与显示规则更新后保持折叠：恢复
  偏好与快照时尊重折叠状态，不再被子目录的展开记录或当前打开文档的路径定位重新打开祖先。
  折叠不会清空子树展开记忆，显式重新展开父目录会恢复已记住的子树；实际打开文件或新进入
  树视图仍会展开目标路径。
- **异步分支的失败与空目录不再混淆** — 各展开分支分别提交当前规则版本的结果：部分分支刷新
  失败时显示安全错误提示，不拿旧条目冒充新排序结果，也不把失败显示成空目录；同一规则版本
  下确实为空的分支不会被永久标记为叶子，规则变化后会重新加载；失败分支不会自动重试，需要
  显式重试。历史恢复失败后，同一路径的下次恢复会重新请求而不是被误跳过。
- **`.pdf` 后缀目录不再被误判为 PDF** — 快照会记录打开条目的类型：打开一个名字以 `.pdf`
  结尾的目录、隐藏后再 reload，仍按目录展示，不会错误地交给浏览器 PDF 查看器。

## 兼容与升级

- **URL 与接口** — `sort=Column:Order` 的大小写敏感语法与非法值 404 保持不变，新增
  `hidden=0|1`（非法值同样 404）。树 JSON `GET /__/tree` 的响应结构不变，只是开始接受
  `sort`/`hidden`；搜索新增的安全 fragment 只返回 CB 生成的 HTML（nosniff、不携带 token、
  保留真实 HTTP 状态与 `Retry-After`），`download`/`raw` 的优先级不变。
- **安全不变量保持** — 原始内容 origin sandbox、PDF/音视频兼容例外与 `nosniff`、Range
  请求、全部完整页的反嵌入头、native-open 的四道门与 Office/搜索的有界 job permit 生命周期
  均未改变。本机打开仍只在带合法 token 的完整目录/搜索页的列表与网格中可用，树视图不携带
  token，切回时通过同上下文完整页恢复能力；PDF 仍交给浏览器原生查看器以新 tab 打开。
- **不改变的范围** — CLI 参数、单文件分发、零运行时外部依赖、渲染管线与既有文档能力
  （含 v0.3.1 已发布的 Mermaid 渲染）、响应模式优先级、路径解析与编码 identity 均不变；
  本次未新增依赖。
- **升级提醒** — 前端资源全部内嵌在二进制中：正在运行的 chapbook 进程不会自动获得本次
  更新，需要替换为新二进制后重启原有进程；除此之外无需数据迁移。
- **平台** — 与上一版相同的发布目标：`x86_64-unknown-linux-musl`（musl 静态链接，不依赖
  发行版 glibc 版本）与 `aarch64-apple-darwin`（Apple Silicon）。其他平台可按 README 从
  源码构建。
- **文档** — 使用说明见
  [README](https://github.com/weiwen99/chapbook/blob/v0.4.0/README.md)，行为契约与安全
  不变量见 [AGENTS.md](https://github.com/weiwen99/chapbook/blob/v0.4.0/AGENTS.md)，树模式
  客户端外壳架构见
  [ADR 0001](https://github.com/weiwen99/chapbook/blob/v0.4.0/docs/adr/0001-tree-mode-client-shell.md)。
