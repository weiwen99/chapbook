# 04: 统一浏览视图、偏好、上下文与历史

**What to build:** `chapbook-browser.js` 用唯一的三态浏览视图与共享显示规则驱动目录、搜索、树和预览，完成偏好迁移、焦点保持与历史恢复。

**Blocked by:** None（[02](02-listing-query-and-fragments.md)、[03](03-unified-browser-toolbar.md) 已完成）。

**Status:** ready-for-agent

## Context

完整决定见 [spec.md](../spec.md)，特别是 Q4、Q6、Q13–Q18、Q23–Q27。显示偏好、显示规则、选中条目和打开条目是不同概念，见 [GLOSSARY.md](../../../GLOSSARY.md)。

## Required change

- 浏览视图只有 tree/list/grid 一个真源；树壳是否活跃由它驱动，不保留可独立变化的 cb-mode 与 cb-view 二级开关。迁移旧偏好一次：旧 tree 优先，否则保留 grid/list，写入新三态后删除旧 cb-mode；不保留长期兼容别名。
- 保留现有树展开/选中/宽度/折叠偏好，不因控件 cutover 清空。新隐藏/排序偏好在同源范围保存；存储不可用时当前页仍可在内存中使用，沿用既有容错，不要求 cookie。
- 没有有效历史/恢复快照的新访问按显式 URL > 保存偏好 > 默认取得显示规则；首次文档直链保留独立阅读表面，浏览偏好不构成第四种阅读布局。初始化规范化前消费有效 managed 快照；reload、popstate 与 pageshow/BFCache 按该项恢复，不重读其他 tab 的偏好来覆盖历史布局。显式链接、历史恢复与初始化不能回写长期偏好；控件只保存改变的字段，不把其他临时 URL 规则存成默认。
- 分享 URL 只有路径、q、sort、hidden 和文档 hash；不加入 layout，不误用响应模式 view=1。raw/fragment/download 等 fetch 模式不泄露到 pushed URL。
- 同一位置的控件变化 replace 当前历史项；真实路径/搜索导航新增历史，文件进入父目录是实际导航。managed 快照保存浏览/独立阅读表面、浏览时的 tree/list/grid、上下文位置/q/hash、有效显示规则，以及打开/选中条目各自的编码 identity 和打开条目的 dir/file 类型；不保存 token 或正文，不从共享树选中偏好猜恢复对象。跨完整页目标项也携带快照，只形成一个目标历史记录；同路径补能力 replace 后 reload，不新增历史。不沿用 replaceState/pushState(null) 擦除快照，保留既有锚点规则。
- 切换目录视图保留位置。看文件时列表/网格进入父目录并定位该文件，回树仍显示原文件；独立阅读页采用相同入口逻辑。区分打开条目与选中条目，不用 selectedIndex 反推出文件 identity。
- 搜索页允许树视图，右侧展示同一查询的安全搜索片段；仅换视图不丢查询。树目录节点的既有展开/收起语义保持；实际打开另一条目才离开当前搜索上下文，后退能回到搜索。
- 隐藏/排序改变立即更新当前规则、当前历史项及用户改动的偏好字段，刷新当前条目展示、目录预览和已展开分支；受影响区域进入新版本加载状态，不让旧集合冒充新规则下可操作的结果。树缓存、空分支状态与在途结果带有效选项版本；成功、当前版本失败、过期有可区分的结果，旧成功和旧错误都不提交。不沿用成功/失败均 resolve 为 undefined 的加载 Interface；复用取消/导航代次 seam，不加自动重试。
- 重排保持当前打开内容、展开状态和可见选中条目。隐藏按 Q17 回退焦点，不打开回退项、不改变 pathname/q/hash；控件仍更新 hidden query。正常目录空结果仅是当前选项版本没有可见孩子，不永久叶子化或删除待恢复的展开意图；选项版本改变后失效并重取，显示回来恢复展开，不抢旧焦点。环/非 UTF-8 的服务端不可展开状态保持；隐藏目录直链不强制显示隐藏项。
- 分支刷新部分失败时，成功分支安装新数据；当前版本失败的分支显示安全错误状态，不保留可操作旧集合、不视为空目录、不删除待恢复展开意图，打开内容保留。过期错误与成功都丢弃，不增加自动重试。
- 分开请求目标与成功安装内容。目录/搜索的成功内容键包含上下文、q 与 ListingOptions，文档正文不依赖 listing 规则，不能为排序/隐藏重转换已打开文档。只有一致且成功安装才可跳过加载；错误/忙占位不记为可跳过重取的成功。普通 fragment 导航失败不提交目标历史/上下文；历史恢复失败保留浏览器已切换的 URL/快照并显示错误，同时失效成功标记，不能仅因同 pathname 而跳过后续加载。原生完整页失败沿用浏览器导航及既有 HTTP 状态。
- `v` 在浏览视图中循环列表→网格→树→列表；输入框、可编辑区、修饰键组合不触发，保留其余树键盘规则。
- native-open 保留合法完整页 token 下目录与搜索列表/网格的既有能力，树仍无本机打开。补能力加载当前上下文的完整可信页：搜索保持 `/__/search` 与 q/sort/hidden，不退到目录；目录保持目录位置。按上述快照规则恢复布局与目标定位，不从 fragment 取得/传播 token，也不把 token 放进历史快照或持久存储。
- PDF 仍按 file kind + 编码后缀两条件新 tab 原生查看，目录 folder.pdf 不受影响。URL/action identity 始终编码传递，不 decode；native form 恰好 decode 一次；非 UTF-8 display-only 行不生成操作。
- 删除旧散落模式按钮、旧树顶栏迁移模式按钮逻辑与 obsolete 注释，不留下两套事件入口或反向同步 shim。

## Acceptance criteria

- [x] 列表→网格→树切换保留隐藏、排序、目录/文件/查询，URL 与实际内容一致。
- [x] 显式链接、初始化与前进/后退均不污染长期偏好；用户只改某一项时其他临时规则不被误保存。
- [x] 同位置控件变化与补 token reload 不增长历史；真实导航只新增一个目标项，跨完整页后退/前进、reload 与 BFCache 恢复对应表面/布局/规则及独立打开/选中 identity，即使其他 tab 改过长期偏好。
- [x] 旧 tree/grid/list 偏好一次迁移后仍被尊重，旧 cb-mode 不再作为第二真源。
- [x] 多级树重排不收起；隐藏焦点回退只更新 hidden query，不导航或改变内容；隐藏分支及仅含隐藏孩子的正常目录显示回来恢复展开、不抢焦点；结构性不可展开状态不被复活。
- [x] 快速切换、慢响应与历史中断不能回灌旧成功/旧错误；两个展开分支一成一败时各自显示新数据/安全错误，保留内容与展开意图；历史加载失败使成功标记失效，同路径后续恢复会重新加载，不出现伪排序成功。
- [x] 文档直链、搜索、目录预览、PDF、native-open 和非 UTF-8 identity 满足契约；搜索树→列表/网格保留 q/规则及本机打开能力，隐藏/排序不重转换已打开文档，快照与 fragment 均无 token。
