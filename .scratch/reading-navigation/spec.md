# 独立阅读页导航

Status: implemented

Product decisions: confirmed (Q1–Q13)
Final confirmation: confirmed (Q14)

本文件记录 grilling 已确认的产品设计、实现边界与验收结果。用户在 Q14 确认完整规格，随后要求继续实施；本轮已完成实现与验证。

## 目标与范围

独立阅读页围绕单个文件的阅读组织导航，不再复用浏览视图的工具区。顶部回答三个问题：当前文件在哪里、如何回到文件浏览、能对当前文件做什么。

覆盖 CB 生成的 Markdown、Org、代码、Office／CSV 独立阅读页。目录页、搜索结果页和树视图内部的浏览工具区不在本次视觉重设计范围内；为连接阅读页与浏览视图所必需的导航交接属于本次范围。PDF 继续使用浏览器原生查看器。

## 改动前依据

- [GLOSSARY.md](../../GLOSSARY.md) 已将独立阅读页与树、列表、网格三种浏览视图区分。文件搜索与所在目录的确定含义在本次讨论中即时补充。
- 改动前，`src/render.rs` 的 `doc_page` 调用同一 `topbar`，阅读页输出搜索输入框、三视图图标组、禁用的隐藏项与排序控件。
- 已在用户提供的文档地址打开真实浏览器：页面为 `data-cb-surface="reading"`，顶部搜索表单指向 `/__/search`，列表图标链接指向文件父目录；页面没有位置面包屑。该观察针对正在运行的实例，不声称其二进制由本轮构建。
- 改动前，`assets/chapbook-browser.js` 的 `readingListGridTarget` 同时设置选中条目与打开条目；`switchToView('tree')` 替换当前历史项。Q12、Q13 改变从独立阅读页出发的这两条语义，不借此修改浏览视图内部的既有交互。
- 旧[浏览视图控件规格](../browser-view-controls/spec.md) Q14 要求阅读页共用三视图图标、禁用隐藏与排序，本需求明确替代该阅读页约定。旧规格的非固定工具区约定也不再适用于独立阅读页；浏览页面不因此改变。
- [ADR 0001](../../docs/adr/0001-tree-mode-client-shell.md) 的客户端树壳、服务端不感知浏览布局与安全能力隔离继续成立。

## 已确认决定

用户对第一轮 Q1–Q3、第二轮 Q4–Q9、第三轮 Q10–Q13 均答复“全部接受你的建议”。

| 问题 | 确认结果 |
| --- | --- |
| Q1：范围 | 所有 CB 生成的独立阅读页采用一致导航；目录、搜索、树内部浏览工具区不重设计；PDF 除外。 |
| Q2：职责 | 阅读页提供文件位置、返回浏览和文件操作；移除常驻三视图切换组及禁用的隐藏／排序控件。进入目录或文件树是明确导航动作。 |
| Q3：搜索地位 | 取消常驻大搜索框，文件搜索保留为次级入口；本文查找继续使用浏览器的 `⌘F / Ctrl+F`。 |
| Q4：返回目的地 | 入口名为“所在目录”，固定进入当前文件的父目录；不猜测来源页面。进入目录延续显示规则并定位当前文件；返回来源由浏览器后退负责。 |
| Q5：文件身份 | 顶栏主信息为可点击路径面包屑与实际文件名；正文标题留在正文，不重复搬进顶栏。 |
| Q6：文件树 | 保留次级动作“在文件树中浏览”，进入树视图后仍以当前文件为阅读对象。 |
| Q7：文件操作 | 仅提供“下载原文件”与“复制链接”。下载原始字节而非渲染 HTML；复制当前 URL 并保留已有章节锚点。不增加字号、主题、打印或本机应用打开等阅读工具。 |
| Q8：搜索交互 | 点击搜索入口展开轻量输入区；提交后进入现有文件搜索结果页，不边输入边替换正文，不新增实时搜索或正文检索。 |
| Q9：滚动行为 | 紧凑顶栏在阅读滚动时保持窗口顶部可见，不按滚动方向自动显隐；正文标题和右侧章节目录不重复搬进顶栏。 |
| Q10：布局与收纳 | 宽屏为单行：左侧“所在目录”，中部路径面包屑与文件名，右侧文件树、搜索、下载、复制链接。长路径折叠中间祖先段并可展开访问。窄屏保留“所在目录＋文件名＋更多”；“更多”包含完整可点击路径、完整文件名和所有次级操作，不依赖悬停才能看全。 |
| Q11：返回布局 | “所在目录”沿用用户已保存的浏览视图，无偏好时使用列表；该导航不改写显示偏好，无 JavaScript 时使用服务端列表。 |
| Q12：定位边界 | 条目定位只选中并滚动到目标，不自动打开预览。目标受隐藏规则过滤时只进入所在目录，不开启隐藏项、不注入过滤例外、不打开替代条目。 |
| Q13：历史语义 | 独立阅读页进入文件树是实际导航，新增一个历史项；后退恢复独立阅读页及原阅读位置。同一浏览位置内的布局切换仍沿用原有历史规则。主动进入树按现有约定保存树偏好，历史恢复不回写偏好。 |

## 交互落地边界

以下要求落实已确认行为与现有基本可用性约定，不增加新的阅读功能：

- **位置语义**：路径从服务根目录开始；根目录下的文件也有可用的“所在目录”入口。当前位置的文件名用于标识，不伪装成另一个目录。文件名与正文标题即使相同也不合并它们的语义。
- **表面切换**：进入树后显示既有浏览工具区，不叠加独立阅读导航；回到独立阅读页时恢复阅读导航。目录、搜索、树内部的工具区保持现状。
- **滚动布局**：顶栏保持可见，但不能盖住锚点跳转后的标题、键盘焦点或右侧文档目录。长路径、长文件名和操作展开区不能撑出页面横向滚动；被折叠内容必须能用键盘与触控完整访问。
- **搜索焦点**：既有 `/` 快捷键在阅读页展开并聚焦文件搜索；输入框与可编辑区内不抢按键。收起输入区后焦点回到搜索入口，提交仍使用现有搜索端点与显示规则。
- **复制反馈**：复制的是当前页面真实 URL，包含已有章节锚点，不把滚动高亮的章节擅自写入链接。剪贴板不可用或写入失败时提供可选择的完整链接供手动复制，不显示虚假的成功反馈。
- **渐进增强**：无 JavaScript 时保留真实路径链接、下载链接和可展开的原生搜索表单；依赖 JavaScript 的文件树与复制能力不伪装为可执行操作。
- **历史保存**：补足阅读位置恢复所需的历史状态，但不存储文档正文或 token。新导航只形成一个目标历史项；恢复阅读页不能被刚保存的树偏好重新覆盖。

## 保持的既有约束

- 文件位置使用当前访问路径，不跳到符号链接目标的真实文件系统路径，不展示服务根目录之外的位置。
- 文件名显示与 action identity 分离：显示复用安全转义与双向隔离；导航使用完整 root-relative 路径的逐 segment 编码，不能由正文标题或显示文本重建。
- 隐藏是浏览过滤而非访问权限。文件直链、原始文件与下载的既有访问语义不变。
- `sort`／`hidden` 继续按既有规则传递；搜索提交沿用当前显示规则。分享链接不增加布局参数，`view=1` 仍是响应模式。
- 阅读页不携带 native-open token，不把该能力转交树壳、fragment、历史快照或存储。
- 下载、Range、raw／fragment／view 优先级、可信 UI 安全响应头、PDF／媒体例外保持现有契约。
- 树与网格仍依赖 JavaScript；实际链接／表单可用的所在目录、路径导航、下载和文件搜索保留无 JavaScript 的基本可用性。
- 新导航继承现有亮暗主题、可访问名称、键盘与触控可操作性，不引入外部资源或 inline handler。

## 验收契约

以下场景是必须保持的行为契约。界面行为需在真实浏览器中验证，不能只靠 HTML 或源码字符串断言；本轮执行结果见下节。

| 场景 | 可观察结果 |
| --- | --- |
| Markdown、Org、代码、Office／CSV 独立阅读页 | 使用一致的阅读导航；不再出现三视图切换组和禁用的隐藏／排序控件。正文标题与既有章节目录保留。 |
| 文件名与正文标题不同；文件位于服务根目录或多级子目录 | 顶栏显示实际访问路径和文件名；祖先链接与“所在目录”进入正确目录，不从正文标题构造路径。 |
| 返回目录，分别有列表／网格／树偏好或没有保存偏好 | 使用保存的视图或默认列表，延续显示规则；可见目标被定位而不自动打开预览，此导航不改变保存偏好。 |
| 隐藏文件直链；树中存在被隐藏过滤的祖先 | 返回所在目录不自动显示隐藏项、不创建过滤例外，不为定位改写偏好或打开其他文件。隐藏目录直链仍遵守既有访问契约。 |
| 阅读到正文中部后进入文件树，再后退／前进 | 树仍打开同一文件，只新增一个目标历史项；后退恢复独立阅读页与原阅读位置，前进恢复树；历史恢复不改写显示偏好。 |
| 在浏览视图内部切换布局、隐藏与排序 | 保持原有历史语义及控件行为，不受阅读导航重设计影响。 |
| 点击搜索入口或按 `/`，输入后提交 | 输入前后正文不被实时替换；提交进入已有文件名搜索结果页并保留显示规则。输入与可编辑区不被快捷键打断。 |
| 下载与复制带章节锚点的链接 | 下载得到原文件字节；复制保留真实 URL 与锚点。模拟剪贴板不可用／拒绝时可手动复制完整链接，没有虚假成功。 |
| 宽屏、窄屏、长路径、长文件名、键盘及触控 | 按 Q10 收纳，所有路径与操作均可达；页面没有由顶栏引起的横向溢出；完整信息不依赖 hover。 |
| 长文滚动、章节跳转、亮暗主题 | 顶栏持续可见且不遮挡目标标题或文档目录，颜色与现有主题一致。 |
| 禁用 JavaScript | 所在目录、面包屑、搜索与下载可用；不出现假文件树、假复制成功或失效的浏览视图切换组。 |
| 路径含空格、字面 `%`／`+`、Unicode／控制字符或符号链接别名 | 保持安全显示与精确编码 identity，不误解码、不从显示文本反推路径，不暴露服务根目录外的真实路径。 |
| 目录／搜索页面、树内文档与 fragment、PDF | 浏览工具区不重设计；fragment 不包含独立阅读导航；PDF 仍交给原生查看器，既有安全能力边界不变。 |

## 实施与验证

- `src/render.rs` 输出独立阅读导航与真实链接／表单；浏览工具区置于惰性模板，只在进入树壳时安装。
  `assets/chapbook-doc.css` 负责吸顶、章节偏移与宽窄布局；`assets/chapbook-browser.js` 复用既有浏览状态与历史交接，补充阅读滚动位置、搜索焦点和复制反馈。
- 已删除旧阅读页的列表／网格跳转分支及禁用浏览控件；公开 `doc_page` 调用签名、文件服务和 native-open 安全边界不变。
- 路由回归覆盖精确编码路径、父目录链接和原字节下载；浏览器回归覆盖三种保存视图、隐藏过滤、单次历史导航、阅读位置恢复及窄屏搜索焦点。
  修复了关闭的原生 `details` 子元素仍有布局矩形、导致 `/` 未打开外层“更多”的问题。

另用实际服务与 Chromium 核对：

- Markdown、Org、Rust 代码、CSV、DOCX 均显示独立导航，正文内容与标题保留。
- 无保存偏好时返回根目录使用列表、选中当前文件且不写偏好；隐藏目录直链中的可见文件仍可被定位。
- 1568px 宽屏、390px／320px 窄屏、亮暗主题与长路径／长文件名均无导航横向溢出；完整路径可展开，触控点按“更多”可访问次级操作。
- 长文滚动时顶栏保持可见；章节跳转结束后标题位于顶栏下方。`/`、Escape、搜索提交及输入框内的字面 `/` 均按约定工作。
- 剪贴板授权时读回内容与当前 URL（含锚点）完全一致；拒绝时显示已选中的完整链接，不报告复制成功。下载响应内容与源文件完全一致。
- 禁用 JavaScript 后，所在目录、原生搜索表单和下载链接仍工作；文件树与复制按钮不显示。
- 字面 `%2F`、空格、`+`、Unicode、双向控制字符与符号链接别名保持显示／identity 分离，不泄露真实文件系统路径。

验证期间将 `src/listing.rs` 的原始字节排序测试改用有效的不可见 Unicode 文件名夹具，避免 macOS 拒绝创建非法 UTF-8 文件名；仍验证原始排序与可见转义的区别，不改变排序实现。
